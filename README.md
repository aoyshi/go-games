# go-games

A repository of simple games built with golang and ebitengine. Following blog: https://threedots.tech/post/making-games-in-go/

## Local setup

1. From root dir, run `go mod tidy` to install dependencies
2. Install assets from https://kenney.nl/assets/graveyard-kit, place `.png` files in `src/assets/`
3. From `src/` dir, run `go run main.go` to run game
